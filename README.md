🌐 Portfolio Personal - David Gutiérrez Liceras
Este repositorio contiene el código fuente de mi portfolio personal. Es una presentación de mi perfil profesional, 
mi experiencia técnica en sistemas y mis habilidades en desarrollo web y programación.

📐 Estructura de Proyectos (CSS Grid)
La sección Proyectos utiliza CSS Grid para una organización precisa:
Distribución General: Cada proyecto ocupa su propia fila verticalmente.
División Interna (Imagen | Texto): Cada fila está dividida en dos columnas:
Columna 1: Imagen del proyecto (Aproximadamente 33% del ancho).
Columna 2: Descripción y enlaces (Aproximadamente 66% del ancho).

⚙️ Cómo Visualizar
Para ver este proyecto localmente, simplemente:
Descargue o clone los archivos (index.html y style.css).
Asegúrese de tener todas las imágenes de referencia en las rutas correctas (ej. ./fondo.jpg, ./Foto.png).
Abra index.html en cualquier navegador web.

Pagina web desplegada: https://portfoliodavidgutierrezliceras.netlify.app/
